# Yarn Inventory SaaS API

Multi-tenant Node/Express/MongoDB API with company isolation, JWT access + refresh sessions, roles (owner/admin/staff), password hashing, rate limiting, Helmet, inventory validation, analytics and audit-ready structure.

## Run
1. `npm install`
2. copy `.env.example` to `.env` and set secrets
3. make sure MongoDB is running
4. `npm run seed` (optional demo data)
5. `npm run dev`
